Average vs Real Return

"The stock market averages 12%." The average is real. But can you plan with it? Run a monthly plan through every period of history, with dividends reinvested and after inflation.

How this works

  • Yearly S&P 500 total returns (dividends reinvested) from Aswath Damodaran's NYU Stern dataset; inflation from the U.S. CPI-U, December to December. Real return = (1 + return) / (1 + inflation) - 1.
  • Simple average = the arithmetic mean of the yearly returns. Compound growth (CAGR) = the constant yearly return that ends at the same place.
  • Your contribution goes in at the end of every month. Each year's return is spread evenly over its 12 months; the claim's projection uses the same rule.
  • "Today's dollars": contributions keep the same purchasing power every year and returns are after inflation, so results are in the same dollars you contribute.
  • Every period of your length is tested, one per start year. Worst, median and best are ranked in today's dollars; the yearly return shown is the constant return that would turn the same contributions into the same ending balance.
  • Fees are subtracted from each year's return. Taxes aren't modeled. This is the same math as the video, checked by an automated test against our Python analysis.
